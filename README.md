# Комплексный финансовый анализ компаний «Татнефть» и UTair

## 📌 О проекте
Анализ финансовой отчетности (РСБУ) двух публичных компаний за 2023–2025 гг. в рамках дисциплины «Финансовый учет».

## 🛠 Моя роль и инструменты
*   Проведение горизонтального и вертикального анализа отчетности (ОФР, Баланс).
*   Расчет мультипликаторов: P/E, P/B.
*   Факторный анализ рентабельности (модель Дюпона): ROA, ROE, ROS.
*   Анализ деловой активности (оборачиваемость запасов, ДЗ, КЗ), ликвидности и финансовой устойчивости.

## 📊 Ключевые выводы
*   Выявлены риски в структуре капитала UTair (отрицательный собственный капитал).
*   Оценена эффективность операционной деятельности компаний через факторные модели.
